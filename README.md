# Earthquake Reinsurance Premium Pricing
Statistical analysis for estimating Excess-of-Loss reinsurance premiums for double earthquake risk using the Peak Over Threshold (POT) method.

## Tools
* R
* RStudio

## Contents
* Data preprocessing
* Peak Over Threshold (POT) analysis
* Generalized Pareto Distribution (GPD) estimation
* Excess-of-Loss premium calculation
* Results and analysis
